# Explorer - 强大而快速的侧边栏搜索切换工具

Explorer 是一个浏览器扩展，提供强大而快速的侧边栏搜索切换功能。它能帮助你更高效地管理和访问你的浏览内容。我们的梦想是星辰大海，致力于打造快捷易用的开源侧栏搜索切换工具。

## ✨ 特性

- 🎯 极简模式：仅一条线，不用时收起，用时展开
- 🌙 暗色模式：支持明暗主题切换
- 🎨 随意拖动：按住拖动鼠标即可排序、分组
- 🔍 主动嗅探：智能添加搜索引擎，让添加过程更轻松
- 📊 智能分组：相关分组自动提前，快速切换当前场景所需的搜索引擎
- ⚙️ 高度自定义：支持自定义添加搜索引擎，在分组标题处单击右键唤起菜单
- 🚀 快速切换：侧边栏快速切换不同的搜索引擎
- 🌈 优雅界面：现代化设计，简洁美观
- 🔧 开源可定制：基于现代化的 Vue 3 + TypeScript 技术栈

## 🛠️ 技术栈

- Vue 3
- TypeScript
- Tailwind CSS
- WXT (WebExtension Tools)
- Vee-validate
- Dexie.js
- 以及更多现代化工具...

## 📦 安装

1. 克隆仓库：

```bash
git clone https://github.com/nexmoe/explorer-xiaoshu.git
cd explorer-xiaoshu
```

2. 安装依赖：

```bash
pnpm install
```

## 🚀 开发

- 开发模式：

```bash
pnpm dev        # Chrome
pnpm dev:firefox # Firefox
```

- 构建扩展：

```bash
pnpm build        # Chrome
pnpm build:firefox # Firefox
```

- 打包扩展：

```bash
pnpm zip        # Chrome
pnpm zip:firefox # Firefox
```
